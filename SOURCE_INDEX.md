# Source and material index

The consolidated report follows the required eleven-section order and includes
a populated contents page, source links and page numbers.

## Winter originals

- diagrams/src/aiqas-system-context.excalidraw — original System Context objects
- diagrams/src/aiqas-use-case.excalidraw — original Use Case objects
- diagrams/src/aiqas-components.excalidraw — original Component Diagram objects

Element IDs, labels, positions and geometry were preserved from the Winter
drawings through their editable Excalidraw clipboard representation. A standard
Excalidraw scene wrapper was added for file opening; full-bounds SVG/PNG exports
were generated from the same elements. The Winter app drawings were retained.

## Prototype

Paper exports are in prototype/exports/paper-*.png. The Paper file URL is in the
README. Five added P0 scenario drawings have editable SVGs in prototype/src/ and
matching PNGs in prototype/exports/. These are static mockups, not a working app.

## Research and verification

research/survey-summary.csv contains aggregate selections from five questionnaire
records. No raw contact details or identifiable questionnaire records are included.
research/*.md contains report-section text and readable comparison/requirements
tables. verification/ contains planned test and outcome measurement conditions.

The report is the consolidated submission artifact; source files support editing
and traceability. Supervisor feedback, client discussions, testing, and another
member's peer review are not claimed where evidence is absent.
